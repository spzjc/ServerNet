让远端服务器通过你本地的 Ubuntu 宿主机代理上网，最安全且最常用的方法有两种：**SSH 反向隧道（推荐，无需公网 IP 或复杂网络配置）** 和 **局域网/VPN 直连**。

由于你通常已经通过 SSH 连接到服务器了，**SSH 反向隧道**绝对是阻力最小的方案。它会将服务器上的某个端口，通过 SSH 加密通道，映射回你本地 Ubuntu 的代理端口。

以下是具体的配置步骤：

### 第一步：准备本地 Ubuntu 的代理

你需要确保本地 Ubuntu 上的代理软件（比如 Clash, V2Ray 等）已经正常运行，并且知道它的 **HTTP 代理端口**或 **SOCKS5 代理端口**（通常默认是 `7890`、`1080` 等）。

* **注意**：如果是通过 SSH 反向隧道，你的代理软件**不需要**开启“允许局域网连接”（Allow LAN），保持默认监听 `127.0.0.1` 即可，这样更安全。

### 第二步：建立 SSH 反向隧道

在你的本地 Ubuntu 终端中，使用 `-R` 参数通过 SSH 连接到服务器。假设你的本地代理端口是 `7890`，你想在服务器上映射的端口也是 `7890`：

```bash
ssh -R 7890:127.0.0.1:7890 username@your_server_ip

```

*参数解释：`-R <服务器端口>:<本地IP>:<本地代理端口>`。这行命令的意思是：将服务器的 7890 端口，映射到本机的 127.0.0.1:7890。*

### 第三步：在服务器上配置环境变量

通过上面的命令成功登录服务器后，服务器的 `7890` 端口就已经等同于你本地的代理了。接下来告诉服务器使用这个端口。

在服务器终端中执行以下命令（临时生效，关闭终端后失效）：

```bash
export http_proxy="http://127.0.0.1:7890"
export https_proxy="http://127.0.0.1:7890"
export all_proxy="socks5://127.0.0.1:7890" # 如果你的代理支持 socks5

```

### 第四步：测试连通性

在服务器上用 `curl` 测试一下能不能访问外网：

```bash
curl -I https://www.google.com

```

如果返回了 `HTTP/2 200` 等状态码，说明配置大功告成，服务器已经顺利借道你的 Ubuntu 上网了！

---

**补充方案：如果你和服务器在同一个局域网（或同一个虚拟局域网如 Tailscale）**

1. 打开你本地 Ubuntu 代理软件的 **“允许局域网连接” (Allow LAN)** 功能。
2. 通过 `ip a` 或 `ifconfig` 获取你本地 Ubuntu 的局域网 IP（假设为 `192.168.1.100`）。
3. 直接在服务器终端设置环境变量：
```bash
export http_proxy="http://192.168.1.100:7890"
export https_proxy="http://192.168.1.100:7890"

```
